# Extracted assets

All files in this directory are generated by `tools/extract_assets.py` from the
original `ski32.exe` (Microsoft SkiFree 1.04, © 1991 Chris Pirih). They are
**copyrighted game assets** — fine for this private porting project, but do not
redistribute them publicly. A public release will need redrawn replacements.

Regenerate everything with:

```sh
python3 tools/extract_assets.py
```

The script is stdlib-only and deterministic: same input, same output bytes.

## Layout

- `sprites/bitmap_NN.png` — the 89 game bitmaps (RT_BITMAP resources 1–89),
  converted from 4bpp DIB to RGBA PNG. Skier animation frames, trees, rocks,
  stumps, moguls, slalom flags/poles, signs, ski-lift parts, dogs,
  snowboarders, the Abominable Snow Monster (walk + eating sequences), the
  title logo and UI hint banners.
- `icons/icon_N.png` — the 6 embedded icons as PNG, with alpha taken from each
  icon's AND mask.
- `icons/app_1.ico`, `icons/app_2.ico` — the two icon groups (`ICONSKI`,
  `ICONSKI2`) rebuilt as standard `.ico` files, usable as app icons for the
  port.
- `strings.json` — the two string tables: window title, pause text, HUD labels
  and `printf` format strings for Time / Dist / Speed / Style, plus the two
  high-score annotations ("<-- that's you!", "<-- try again!").
- `meta.json` — provenance: for every PE resource its file offset, size and
  SHA-256, plus per-bitmap dimensions and the transparency key.

## Transparency

The original sprites are stored **without** masks: each 4bpp bitmap uses white
(RGB 255,255,255) as the background. At startup the game (`FUN_00405ab0`)
builds a 1bpp mask per bitmap by blitting into a monochrome DC — white maps to
"transparent" — and the renderer (`FUN_00401540`) composites sprites with
`SRCPAINT` (mask OR) followed by `SRCAND` (color AND).

The extractor applies the same rule ahead of time: every pure-white pixel
becomes alpha 0 in the PNGs. This is pixel-faithful to what the game renders —
including white details inside sprites, which are transparent in-game too.

## Sounds

There are **no sound resources** in `ski32.exe` (nor in the 16-bit
`SKI.EXE`). The code references 9 `WAVE` resources by id, but `FindResourceA`
returns NULL for all of them — the shipped binary simply has no audio. The
port can either skip sound or source free replacement effects later.
