# Fallback status-display font

`ibm_vga_8x12.png` is the font the port draws the status display (Time /
Dist / Speed / Style) with when no Terminal font was extracted from a
Windows `vgaoem.fon` (see the main README, "Getting the assets"). It is
compiled into the binary.

**Source:** "IBM VGA 8x14" (`Bm437_IBM_VGA_8x14.FON`) from
[The Ultimate Oldschool PC Font Pack](https://int10h.org/oldschool-pc-fonts/)
v2.2 by VileR, © 2016-2020 VileR, licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) (full text
in `LICENSE.txt`).

**Changes:** only printable ASCII (0x20-0x7e) is kept, and each 8x14 glyph
cell is cut to 8x12 (rows 1-12; rows 0-11 for `^` and `` ` ``; `$` loses
its top pixel) to fit SkiFree's 12-pixel status rows. Generated by
`tools/make_fallback_font.py`.

This file, like the original font, is licensed under CC BY-SA 4.0. The
rest of the project's code is under its own license (see `LICENSE`).

Why this font: among the pack's 296 bitmap fonts it is one of the closest
to Windows' Terminal font that SkiFree uses (same 11 rows of ink, bold
strokes, slashed zero) — 189 differing pixels on the status display's
strings, against 0 for the extracted Terminal glyphs.
